# Catatan Amplop

Aplikasi React/Vite dengan Supabase dan Vercel Functions untuk voice, scan amplop, dan scan buku.

Kode aplikasi berada langsung di root repository. Pada proyek Vercel yang sudah ada, hubungkan repository ini dan kosongkan Root Directory. Framework: Vite, Build Command: `npm run build`, Output Directory: `dist`, Node.js: 22.x.

Atur `OPENAI_API_KEY` di Environment Variables Vercel untuk Production. Model vision: `gpt-4.1-mini`; transkripsi: `gpt-4o-mini-transcribe`. Jangan commit API key.

Lihat `VERCEL-AI-SETUP.txt` untuk petunjuk dan batas validasi. Isi database tidak disertakan.
